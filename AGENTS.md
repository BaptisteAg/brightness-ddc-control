# Brightness DDC Control

- Extension GNOME Shell en JavaScript dans `extension/`, déclarée pour les versions 45, 46 et 47 dans `metadata.json`.
- `install.sh` et `uninstall.sh` modifient le système ou la session ; ne pas les exécuter pour une simple revue documentaire.
- Vérification syntaxique des scripts : `bash -n install.sh uninstall.sh` ; aucune suite de tests applicatifs dans ce dépôt.
- Conserver la licence GPL-3.0 et distinguer compatibilité déclarée et essai matériel réellement effectué.
